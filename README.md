# Automated Financial Analytics Pipeline
An end-to-end automated financial analytics solution built using Power BI, Power Automate, Python, APIs, and Google Cloud Platform.

## Project Overview

A survey team operating across multiple locations sends approximately 25 files daily via email. The objective was to automate file collection, consolidation, cleaning, and dashboard generation within a limited reporting timeline.

This project eliminates manual processing by automating:
- Email segregation
- Attachment downloading
- File consolidation
- Data cleaning
- Dashboard updating

  ## Workflow

Field Agents → Outlook Rules → Power Automate → Google Drive → API Integration → Python Transformation → Power BI Dashboard

## Tools & Technologies

- Power BI
- Power Automate
- Python
- Outlook Rules
- Google Drive
- Google Cloud Platform (GCP)
- APIs
- Excel

  ## Key Features

- Automated email filtering using Outlook Rules
- Automatic attachment downloading using Power Automate
- API-based integration between Google Drive and Power BI
- Automated file appending using Python scripts
- Outlier treatment and data cleaning
- Interactive financial analytics dashboard

  ## Key Insights

- Customers aged 30–45 showed highest loan activity
- Student loans were the most preferred loan type
- Teenagers recorded highest credit inquiries
- Writers showed highest payment delays
- Standard Credit Mix represented the largest customer segment

  ## Business Impact

- Reduced manual effort significantly
- Automated processing of 25+ daily files
- Improved reporting efficiency
- Reduced chances of manual errors
- Enabled faster dashboard delivery
